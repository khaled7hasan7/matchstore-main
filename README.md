MatchStore is a powerful, open-source multi-vendor Laravel eCommerce platform designed for modern online marketplaces. Built with scalability, flexibility, and user experience in mind, it provides everything you need to launch and manage a full-featured online store with multiple vendors.

## ✨ Key Features

### 🏪 Multi-Vendor Marketplace
- **Vendor Management**: Dedicated seller panel for vendors to manage their products, orders, and inventory
- **Commission System**: Flexible commission structure for marketplace revenue
- **Vendor Dashboard**: Comprehensive analytics and sales tracking for vendors
- **Independent Storefronts**: Each vendor can manage their own product catalog

### 🌍 Multi-Language Support
- **19 Languages Included**: English, German, French, Spanish, Dutch, Italian, Portuguese, Hindi, Polish, Russian, Turkish, Arabic, Persian, Chinese, Japanese, Indonesian, Vietnamese, Korean, and Thai
- **RTL Support**: Full right-to-left language support for Arabic and Persian
- **Easy Translation**: Simple language file management for adding new languages
- **Auto-Detection**: Automatic language detection based on user preferences

### 📱 Mobile-First Design
MatchStore features comprehensive mobile optimization with dedicated mobile layouts for exceptional user experience on all devices:

**Mobile-Optimized Pages:**
- Home page with mobile-optimized hero sections and product carousels
- Shop/Product Listing with bottom sheet filters and 2-column product grid
- Product Detail with swipeable image galleries and sticky "Add to Cart" button
- Shopping Cart with mobile-optimized item cards and quantity controls
- Checkout with simplified mobile form layout and step-by-step process
- Customer Profile with gradient header and collapsible sections
- Orders List and Order Details with status tracking
- Address Management (list, create, edit) with mobile-friendly forms
- Wishlist with mobile product cards and quick actions
- Contact Page with mobile-friendly form
- Authentication (Login/Register) pages with modern mobile design
- Order Confirmation with success animations and order summary
- Search Results with mobile product grid and instant filtering

**Mobile UI Patterns:**
- Sticky bottom action bars for critical CTAs (checkout, add to cart, save)
- Swipeable image galleries with touch support and dot indicators
- Bottom sheet filters for product filtering and sorting
- Accordion-style collapsible sections to save screen space
- Card-based layouts optimized for mobile readability
- Touch-friendly form controls with larger tap targets (44x44px minimum)
- Mobile-optimized navigation with hamburger menu
- Pull-to-refresh and infinite scroll on product listings

**Technical Implementation:**
- Separate desktop and mobile HTML layouts (`.desktop-only` / `.mobile-only` classes)
- CSS media queries at 768px breakpoint for optimal responsive behavior
- Touch event handling for swipe gestures and mobile interactions
- Mobile-first component design throughout the customer-facing store
- Optimized images and lazy loading for faster mobile performance

### 💳 Payment Integration
- **PayPal**: Full PayPal payment gateway integration
- **Stripe**: Secure Stripe payment processing
- **Cash on Delivery**: COD option for local deliveries
- **Multiple Currencies**: Support for currency conversion and display

### 👥 User Roles & Panels
- **Admin Panel**: Complete control over marketplace, vendors, products, orders, and settings
- **Seller Panel**: Dedicated interface for vendors to manage their business

## 🚀 Installation Guide

Follow these steps to set up MatchStore:

### **Install via Composer**
Run the following command to create a new MatchStore project:
```sh
composer create-project matchsystems/matchstore
```

If you didn't have `.env` you can copy it from `.env.example`.

```sh
cp .env.example .env
```

Create a new database and update the database credentials in `.env`. Run the following command to install MatchStore:
```sh
php artisan install:matchstore --with-import
```

### **Options**
- `--with-import` Imports sample data to help you get started quickly.

Start the Laravel server:
```sh
php artisan serve
```

If you found error `Vite manifest not found at`, you should run this in different terminal:
```sh
npm run dev
```

Your MatchStore instance is now running! Open your browser and visit:
```sh
http://127.0.0.1:8000
```

## 🛠️ Tech Stack

### Backend
- **Framework**: Laravel 10+
- **Database**: MySQL/MariaDB
- **Authentication**: Laravel Sanctum
- **File Storage**: Laravel Storage (with support for local, S3, and other drivers)
- **Queue System**: Laravel Queues for background jobs
- **Cache**: Redis/File-based caching for performance

### Frontend
- **Template Engine**: Blade (Laravel's native templating)
- **CSS Framework**: Bootstrap 5 with custom components
- **JavaScript**: Vanilla JS with modern ES6+ features
- **Icons**: Font Awesome 6
- **Build Tool**: Vite for asset compilation
- **UI Components**: Custom-built responsive components

### Admin Panel
- **DataTables**: Yajra Laravel Datatables for advanced table management
- **Charts**: Chart.js for analytics and reporting
- **Modern UI**: Custom admin theme with responsive design

### Development Tools
- **Package Manager**: Composer for PHP dependencies, NPM for JavaScript
- **Version Control**: Git
- **Code Quality**: PSR-12 coding standards

## 🎨 Customization

### Theme Customization
The Xylo theme is fully customizable. You can modify:
- Colors and typography in theme CSS files
- Layout structure in Blade templates
- Component styling without affecting core functionality

### Adding New Languages
1. Copy an existing language folder in `resources/lang/`
2. Translate the strings in the language files
3. Add the language to the language selector

### Custom Payment Gateways
Extend the payment system by:
1. Creating a new payment provider class
2. Implementing the payment interface
3. Registering the gateway in the payment configuration
